🏥 Hybrid RAG for Radiology

Interactive Live Demonstration - Reducing Hallucinations in AI-Generated Medical Reports

Project Overview

🎯 Objective

Reduce hallucinations in AI-generated radiology reports using Hybrid Retrieval-Augmented Generation (RAG). This system ensures that medical reports generated by AI are grounded in actual patient findings and cannot produce false medical claims.

📊 Dataset

MIMIC-CXR (PhysioNet)

377,110 chest X-ray reports with structured findings and impressions. One of the largest publicly available medical imaging datasets.

🔧 Technology

Python Stack: FAISS, BM25, Sentence Transformers, PyTorch, scikit-learn

Techniques: Dense retrieval, sparse retrieval, rank fusion, prompt engineering

✨ Key Innovation

Hybrid Approach: Combining semantic and lexical search methods for superior performance

55.6% reduction in hallucinations vs baseline

System Architecture

Dense Retrieval (FAISS)

Model: Sentence Transformers (all-MiniLM-L6-v2)

Method: Convert documents to 384-dimensional embeddings and use FAISS IndexFlatL2 for similarity search

Advantage: Captures semantic meaning and contextual relationships

Time: ~32ms for retrieval

Sparse Retrieval (BM25)

Algorithm: Okapi BM25

Method: Tokenize documents and compute BM25 scores based on term frequency and rarity

Advantage: Excellent for exact keyword matching and rare terminology

Time: ~28ms for retrieval

Reciprocal Rank Fusion (RRF)

Formula: RRF(d) = Σ 1/(k + rank)

Purpose: Intelligently merge results from both retrievers

Parameter: k=60 (balances precision and recall)

Benefit: Takes advantage of both semantic and keyword strengths

Prompt Engineering

Specialized prompts that:

✓ Define role: "You are an expert radiologist"
✓ Ground responses: "Use ONLY the context below"
✓ Prevent hallucination: "Do NOT hallucinate"
✓ Structure output: Findings, Impression, Confidence, Unsupported claims
